# Вікі любіць славутасці — Беларусь (Wiki Loves Monuments Belarus)

Інтэрактыўная карта помнікаў гісторыка-культурнай спадчыны Беларусі для ўдзельнікаў міжнароднага фотаконкурсу **Wiki Loves Monuments**.
Праект распрацаваны паводле ўзору польскага інструмента [zabytki.toolforge.org](https://zabytki.toolforge.org/) (рэпазіторый [Eccenux/wlm-zabytki-mapa](https://github.com/Eccenux/wlm-zabytki-mapa)).

---

## Асноўныя магчымасці

1. **Поўная база Дзяржаўнага спіса ГКК Беларусі**:
   - **8 096 аб'ектаў** у базе (7 686 нерухомых помнікаў для WLM, 219 рухомых, 191 нематэрыяльны);
   - **5 671 помнік** з дакладнымі GPS-каардынатамі на карце;
   - **2 425 помнікаў** у рэжыме спіса без каардынат для дапаўнення фатографамі і краязнаўцамі;
   - Сінхранізацыя з **Вікідадзенымі (Wikidata)**.
2. **Візуальны статус фота (Галоўная мэта конкурсу)**:
   - **Чырвоныя маркеры** — аб'екты без фота на Вікісховішчы («белыя плямы», прыярытэт для фатографаў);
   - **Сінія маркеры (1 161 помнік)** — аб'екты, для якіх ужо ёсць фота;
   - Хуткі пераключальнік: `[✓] Толькі без фота`.
3. **Загрузка на Вікісховішча ў 1 клік**:
   - Кнопка **«Загрузіць фота на Вікісховішча»** адкрывае `Special:UploadWizard` з кампаніяй `wlm-by`;
   - Аўтаматычна падстаўляюцца: афіцыйны шыфр ГКК, назва, адрас, каардынаты і службовыя катэгорыі спадчыны.
4. **Геалакацыя («Каля мяне»)**:
   - Кнопка вызначэння GPS-каардынат фатографа са смартфона альбо ноўтбука.
5. **Фільтры і пошук**:
   - Па формах спадчыны (нерухомая WLM, рухомыя каштоўнасці, нематэрыяльная);
   - Па 6 абласцях і г. Мінску;
   - Па ўсіх 118 раёнах;
   - Па катэгорыях аховы (0 — ЮНЕСКА, 1 — міжнародная, 2 — нацыянальная, 3 — рэгіянальная);
   - Па тыпах (архітэктура, археалогія, гісторыя, мастацтва, горадабудаўніцтва);
   - Імгненны пошук па назве, горадзе ці шыфры.
6. **Выбар падкладак карт**:
   - OpenStreetMap (стандартная карта)
   - CartoDB Positron (чыстая светлая карта)
   - Esri Satellite (спадарожнікавыя здымкі высокага разрознення)

## Структура праекта

```
wlm-belarus/
├── index.html           # Галоўная старонка прыкладання
├── style.css            # Стылі і афармленне (WLM branding)
├── app.js               # Кліенцкая логіка Leaflet + MarkerCluster + фільтраў
├── data/
│   └── monuments.json   # Аптымізаваны статычны JSON (8 096 помнікаў)
├── server.py            # Лакальны тэставы сервер
├── run.bat              # Скрыпт хуткага запуску для Windows
└── README.md            # Дакументацыя
```

---

## Лакальны запуск

1. Адкрыйце тэрмінал у тэчцы праекта:
   ```bash
   py server.py
   ```
   або двойчы клікніце па файле `run.bat`.
2. Адкрыйце браўзер па адрасе: **`http://localhost:8085`**.

## Разгортванне (Deployment)

Прыкладанне з'яўляецца **100% статычным (Static Single Page Application)**. Яно не патрабуе базы даных ці Python на серверы і можа працаваць на любым бясплатным статычным хостынгу.

### Варыянт А: Wikimedia Toolforge (Рэкамендаваны)
1. Стварыце tool на Toolforge (напрыклад, `wlm-belarus` ці `zabytki-by`).
2. Скапіюйце файлы праекта ў каталог `public_html/`:
   ```bash
   rsync -avz --exclude '.git' . <username>@login.toolforge.org:/data/project/<tool-name>/public_html/
   ```
3. Сайт будзе імгненна даступны па адрасе: **`https://<tool-name>.toolforge.org`**.

### Варыянт Б: GitHub Pages
1. Стварыце рэпазіторый на GitHub (напрыклад, `wlm-belarus`).
2. Зрабіце `git push` усіх файлаў.
3. У наладах рэпазіторыя (*Settings -> Pages*) уключыце крыніцу **Deploy from a branch (main / root)**.
4. Пры жаданні падключыце карыстальніцкі дамен.
